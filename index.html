Text → Flow Diagram

Syntax
  • A -> B connects two steps; chain them: A -> B -> C
  • A -yes-> B adds a label to the arrow
  • A step ending in ? is drawn as a decision diamond
  • Start, End, Begin, Stop are drawn as rounded terminals
  • A line with a single name adds a step on its own
  • direction: LR on its own line overrides the direction picker
  • Lines starting with # or // are comments
  • Declare elements: person, system, external, container, database, component
  • container Web App [React]: Delivers the UI — name, optional [technology], optional : description
  • boundary Name [Software System] { … } groups the elements declared inside it (boundaries can nest)
  • A -uses [HTTPS]-> B adds a relationship with optional technology
  • Names used in arrows but never declared are drawn as plain boxes
  • direction: LR and # / // comments work as in flowcharts
